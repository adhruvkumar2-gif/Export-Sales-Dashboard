# Export-Sales-Dashboard

📌 Project Overview

This project presents an Export Sales Analysis Dashboard developed using Power BI for XYZ Exports Pvt. Ltd. The dashboard focuses on analyzing export performance across customers, regions, categories, and time.

The primary objective of this project is to provide data-driven insights into sales, profit, and quantity distribution to help businesses optimize export strategies and improve overall profitability.

This project demonstrates real-world applications of Business Intelligence (BI), dashboarding, and performance analytics, making it highly relevant for Data Analyst and BI roles.

📁 Dataset

The dataset used in this project represents export transaction data and includes:

✔ Customer details (Customer Name)
✔ Sales and Profit data
✔ Order Date (monthly breakdown)
✔ Product categories (Office Supplies, Technology, Furniture)
✔ Regional distribution (Central, South, North)
✔ Quantity and Average Order Value (AOV)

The dataset is structured to enable multi-dimensional analysis across time, geography, and customer behavior.

🛠 Tools & Technologies

Purpose-wise tools used in the project:

Data Visualization: Power BI
Data Processing: Power Query Editor
Data Modeling: DAX (Data Analysis Expressions)
🧠 Workflow / Steps
🔹 Data Loading
Imported export dataset into Power BI
Verified structure and column data types
Applied filters for Year and Country selection
🔹 Data Transformation
Cleaned and formatted data using Power Query
Ensured consistency in date formats and categories
Created calculated fields such as total profit and AOV
🔹 Data Modeling
Developed relationships between data fields
Created DAX measures for KPIs such as:
Total Sales
Total Profit
Total Quantity
Average Order Value (AOV)
🔹 Dashboard Development

The dashboard is designed to provide interactive and dynamic insights through:

✔ KPI summary cards
✔ Customer-level profit analysis
✔ Monthly performance trends
✔ Regional and category breakdown
✔ Filters for Year and Country

📌 Key Results & Insights

📈 Strong Export Performance:
The company achieved approximately 5M in total sales, indicating a robust export business.

💰 Profit Insights:
Total profit stands at 283K, with certain months contributing significantly more than others.

👥 Customer Analysis:
A small group of customers contributes a major share of total profit, highlighting key accounts.

🌍 Regional Trends:
Central region dominates with over 55% contribution, making it the primary market.

📦 Category Insights:
Office Supplies lead in quantity, suggesting high demand in this segment.

📊 Seasonality:
Profit trends show fluctuations across months, with peak performance observed in mid-year.

🎯 Conclusion

The Export Analysis Dashboard effectively converts raw export data into actionable insights through interactive visualizations. It enables stakeholders to track KPIs, identify high-performing regions and customers, and optimize business strategies.

This project highlights the importance of data-driven decision-making in international trade and export operations.
